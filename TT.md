# 📌 Техническое задание (ТЗ)
## Проект: Telegram AI Notes Bot + Mini App

---

# 1. 🎯 Цель проекта

Создать Telegram-бота с Mini App, который:
- принимает **голосовые и текстовые заметки**
- преобразует голос → текст
- автоматически разбивает и классифицирует заметки
- сохраняет их в структурированные папки (разделы)
- предоставляет удобный интерфейс управления заметками внутри Telegram

---

# 2. 🧠 Основной функционал

## 2.1 Входящие данные

Поддержка:
- 🎤 Голосовые сообщения (voice, .ogg)
- 📝 Текстовые сообщения

---

## 2.2 Обработка голоса (STT)

### Поток:
1. Получение `file_id` от Telegram
2. Запрос `getFile`
3. Скачивание `.ogg` файла
4. Отправка в STT API (Whisper или аналог)
5. Получение текста

### Требования:
- Поддержка русского языка
- Без конвертации аудио
- Время ответа ≤ 5 секунд

---

## 2.3 Guard-фильтр (обязательный этап)

### BEFORE LLM (дешёвый фильтр):
Игнорировать:
- сообщения содержащие `?`
- сообщения длиной < 5 символов

---

### LLM Guard:
Если текст не является заметкой (вопрос, диалог, мусор), вернуть:

```json
{ "ignore": true }

Если ignore = true → дальнейшая обработка НЕ выполняется

2.4 Обработка текста (LLM)
Общие правила:
Ответ должен быть строго валидным JSON
Без текста вне JSON
Без комментариев
Без пояснений
temperature = 0
Этап 1 — Разбиение на смысловые части

Вход:

Купить молоко и проверить сервер

Выход:

["Купить молоко", "проверить сервер"]
Этап 2 — Классификация

Категории:

tasks — задачи
ideas — идеи
shopping — покупки
notes — прочее
Формат ответа:
{
  "items": [
    {
      "text": "Купить молоко",
      "type": "shopping",
      "category": "покупки"
    }
  ]
}
Требования:
Каждая мысль должна быть отдельным объектом
Обязательно наличие type
Обязательно наличие category
Если категория не определена → использовать notes
2.5 Обработка ошибок LLM
Парсинг:
использовать JSON.parse() с try/catch
Retry:

Если JSON невалидный:

отправить повторный запрос:
"Ты вернул невалидный JSON. Исправь формат"
повторно распарсить
Fallback:

Если снова ошибка:

сохранить как:
{
  "items": [
    {
      "text": "исходный текст",
      "type": "notes",
      "category": "notes"
    }
  ]
}
