# Smoke Test — AI Notes Bot + Mini App

Короткий ручной сценарий перед деплоем или после крупных изменений.

## Окружение

| Сервис | URL |
|--------|-----|
| Worker | `https://notes-bot-simple.goorbunoov95.workers.dev` |
| Mini App | `https://notes-miniapp.pages.dev` |
| Health | `GET /health` на Worker |

## 1. Worker

- [ ] `GET /` → `AI Notes Bot is running`
- [ ] `GET /health` → `{ "status": "ok" }`
- [ ] `GET /api/notes` без авторизации → `401`
- [ ] `POST /webhook` без секрета → `401` (если `TELEGRAM_WEBHOOK_SECRET` задан)

## 2. Telegram Bot — текст

- [ ] `/start` — приветствие и онбординг (или welcome-back для существующего пользователя)
- [ ] `/help` — справка
- [ ] `/app` — ссылка на Mini App
- [ ] Текст «Купить молоко и позвонить врачу #дом» → классификация и ответ бота
- [ ] Короткий текст «да» → понятный отказ без сохранения
- [ ] Текст с `<script>` → корректный HTML в ответе

## 3. Telegram Bot — голос

- [ ] Короткое голосовое → распознавание и сохранение
- [ ] Голос > 5 мин → сообщение об ошибке

## 4. Mini App

- [ ] Открывается из Telegram, список заметок загружается
- [ ] Фильтры по типу работают
- [ ] Поиск находит созданную заметку
- [ ] Редактирование и удаление заметки (soft delete → корзина)
- [ ] Создание заметки из Mini App
- [ ] Корзина: восстановление и удаление навсегда
- [ ] Экспорт JSON (кнопка ⬇ в шапке)
- [ ] Напоминание в редакторе заметки (`remind_at`)
- [ ] Ошибка API показывается пользователю (toast)

## 6. Фаза 7 (корзина / экспорт / напоминания)

- [ ] `DELETE /api/notes/:id` — soft delete, заметка в `?trash=1`
- [ ] `POST /api/notes/:id/restore` — восстановление из корзины
- [ ] `GET /api/export?format=json|md` — экспорт заметок
- [ ] Напоминание: `PUT` с `remind_at` → cron `*/15 * * * *` → сообщение в Telegram

## 5. Папки

- [ ] Быстрый онбординг создаёт папки без дубликатов при повторе
- [ ] Заметки попадают в папку по `category`, не только по названию
